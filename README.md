# Portfolio – KONE FATIMAT MERAJA BENEDICTE

Portfolio personnel développé en **HTML, CSS et JavaScript**, à partir d'une maquette conçue sur **Figma**.

Il présente principalement :
- **qui je suis** : ma présentation, mon parcours et mes centres d'intérêt ;
- **ce que je sais faire** : mes compétences en développement web, mobile et en programmation ;
- **ce que j'ai réalisé** : mes projets, mes certifications et mon CV ;
- **comment me contacter** : mes coordonnées, mes réseaux et un formulaire de contact.

## Liens

- **Site en ligne :** https://fatimat-bot.github.io/Mon_Portfolio/

## Structure de la page

| Section | Contenu |
|---|---|
| Header | Logo et menu burger (Accueil, À propos, Compétences, Projets, CV, Contact) |
| Accueil | Photo, nom, titre et boutons « Voir mes projets » / « Me contacter » |
| À propos | Présentation, parcours et centres d'intérêt |
| Ma boîte à outils | Compétences classées : web, mobile, programmation, outils |
| Mes projets | 3 projets ; la description, les technologies et les liens apparaissent au survol |
| CV | Formation, certifications et téléchargement du CV |
| Contact | Coordonnées, liens LinkedIn et GitHub, et formulaire de contact |
| Footer | Copyright et signature |

## Technologies utilisées

- **HTML5** : structure sémantique (`header`, `main`, `section`, `article`, `footer`)
- **CSS3** : variables, Flexbox, Grid, animations et design responsive (ordinateur, tablette, mobile)
- **JavaScript** : menu burger, lien actif pendant le défilement, formulaire de contact et apparition des éléments au défilement (`IntersectionObserver`)
- **Figma** : conception de la maquette

## Organisation des fichiers

```
portfolio/
├── index.html           → structure de la page
├── style.css            → mise en forme et responsive
├── script.js            → interactivité
├── CV_Kone_Fatimat.pdf  → CV téléchargeable
└── images/              → photos, captures des projets et certificats
```

## Voir le projet en local

1. Télécharger ou cloner le dépôt :
   ```bash
   git clone https://github.com/Fatimat-bot/Mon_Portfolio.git
   ```
2. Ouvrir `index.html` dans un navigateur (ou avec l'extension Live Server de VS Code).
